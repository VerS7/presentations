# Speaker Notes Standard

Speaker notes are conversational delivery guides, not a script to be read word-for-word.

---

## 1. Per-Slide Speaker Notes Template

When drafting notes for any presentation, use this standardized structure:

```markdown
### Slide [N]: [Slide Title]

**Key Takeaway:** [The ONE thing the room must remember from this slide]

**Opening Hook:** [Conversational first sentence to transition into this slide]

**Talking Points:**
- [Bullet 1: Background context or underlying data point not printed on the slide]
- [Bullet 2: A concrete customer anecdote, operational metric, or analogy]
- [Bullet 3: Anticipated question or objection and how to answer it]

**Stage Direction / Cues:** (Pause for 2 sec / Click to reveal / Ask for a show of hands)

**Bridge to Next Slide:** [Natural verbal transition sentence to the next topic]
```

---

## 2. Best Practices for Natural Delivery

1. **Don't Read the Slide:** If a bullet is already written on the slide, the audience has read it in the first 2 seconds. Use notes to explain *why* it matters or *how* we achieved it.
2. **Include Pauses:** Mark critical takeaways with `(Pause for emphasis)`. Giving the audience 2–3 seconds of silence forces them to absorb the point.
3. **Handle Edge Cases:** Include 1 defensive note per slide addressing likely objections (e.g., "If CFO asks about migration cost, note that ROI break-even is 4.2 months").
